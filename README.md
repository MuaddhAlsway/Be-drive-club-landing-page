# 🚗 BE-Drive Club Landing Page

Welcome to the **BE-Drive Club** project — a car-themed landing page designed using **React** and **Vite**.

## 📖 About the Project

This project presents a stylized landing page for a fictional driving club called **"BE-Drive Club."** It includes:

- 🖼️ A full-screen background image with a welcoming title.
- 🔴 A **"Drive Now"** call-to-action button.
- 🏁 Featured sections:
  - 🌀 **Drift Session** — Explore the thrill of drifting.
  - 🏆 **Be Ready!** — Get prepared to win.
- 📎 A structured footer with:
  - 📞 **About Us**
  - 💼 **Our Services**
  - 🔐 **Log In**

> 🎨 All styles are handled with inline CSS in JSX.

## 🚀 Getting Started

### ✅ Prerequisites

- 🟢 Node.js
- 📦 npm or yarn

### 🧑‍💻 Installation

1. Clone the repository:
   ```
   bash
   git clone https://github.com/yourusername/be-drive-club-landing-page.git
   cd be-drive-club-landing-page

    Install dependencies:

2. npm install
```
    Run the development server:
    
    npm run dev
    
    Visit in browser:

    http://localhost:5173
 ```
